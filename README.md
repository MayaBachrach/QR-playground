# QR Playground

סטודיו ניסיוני לעיצוב קודי QR אמנותיים.

## Features
- Generate QR codes from text or URLs
- Customize dot and corner shapes and colors
- Add a center image/logo and adjust its size
- Choose error correction level
- Export PNG and SVG
- Optional browser-based scan test using BarcodeDetector

## Run
Open `index.html` in a modern browser with an internet connection. The QR rendering library is loaded from jsDelivr.

## Important
A visually valid QR code is not necessarily reliably scannable. Always test on multiple devices before printing. Browser scan testing depends on BarcodeDetector support.

## Next steps
An interactive module editor and automated scanability feedback are planned; they are not implemented yet.
